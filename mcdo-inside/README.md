# McDonald's — Inside the Golden Arches (Hyperframes)
Vidéo explicative isométrique 85 s, 1920x1080. Création indépendante, non affiliée à McDonald's ; logo stylisé non officiel.
Lancer : `npx hyperframes preview` — Export : `npx hyperframes render -f 30 --crf 18 -o renders/mcdo.mp4`
Audio : `python3 tools/make_audio.py` (musique/effets) + voix off Kokoro (assets/vo).
